# Telegram-бот: регионарная анестезия (архитектура NYSORA Nerve Blocks)

Русскоязычный бот-справочник для анестезиологов и реаниматологов.

## Что внутри
- NYSORA-структура карточек блока (обзор, показания, противопоказания, анатомия, позиционирование, цель, техника, советы, осложнения, объём).
- Фото и видео для каждого блока.
- 3 уровня детализации: базовый, стандартный, продвинутый.
- JSON-контент в `content/blocks_ru.json`.

## Быстрый запуск (сделано максимально "под ключ")

### Вариант 1: локально (рекомендуется для старта)
```bash
bash scripts/setup_local.sh
# вставьте BOT_TOKEN в .env
source .venv/bin/activate
python bot.py
```

### Вариант 2: запуск через Docker
```bash
cp .env.example .env
# вставьте BOT_TOKEN в .env
docker compose up -d --build
```

## Прод-старт одной командой
```bash
# BOT_TOKEN берется из .env или из переменной окружения
bash scripts/run_prod.sh
```

## ВАЖНО про токен
- Не публикуйте токен в чатах/репозиториях.
- Если токен уже попал в чат — сразу перевыпустите через @BotFather.
- `.env` исключен из git через `.gitignore`.

## Структура проекта
- `bot.py` — логика бота и меню.
- `content/blocks_ru.json` — база блоков.
- `scripts/setup_local.sh` — автонастройка локального окружения.
- `scripts/run_prod.sh` — безопасный запуск с проверкой `BOT_TOKEN`.
- `Dockerfile`, `docker-compose.yml` — контейнерный запуск.
